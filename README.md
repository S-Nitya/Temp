## 🚀 The "Consolidated Hive" Architecture (6 specialized agents)
1.  **Intelligence Hub**: Real-time environmental analysis (Spoilage Risk, Quality Grade).
2.  **Strategic Brain**: **Time-Decay Pricing Intelligence** (Premium Scalping -> Market Alignment -> Smart Liquidation).
3.  **Tactical Negotiator**: **Inferential Intelligence** engine that deduces buyer urgency from dialogue history.
4.  **Integrity Watchdog**: SOTA Risk Auditor for detecting collusion and market manipulation.
5.  **Chaos Injector**: Adversarial Red-Teamer for market shock stress-testing.
6.  **Post-Mortem Critic**: Automated SWOT analysis of session economic performance.

## 🛠️ Technical Innovations & "Advanced Dynamics"
- **Inferential Intelligence**: The seller no longer needs explicit labels. It **infers** if a buyer is `ESSENTIAL` (urgent), `CALCULATED`, or `IMPULSE` by analyzing conversation history and persistent counter-offers.
- **Hybrid Urgency Model**: Buyers possess multi-item shopping lists and a **Desperation Factor** that increases as simulation time expires, mirroring real-world consumer behavior.
- **Dynamic Price Discrimination**: The Hive uses social intelligence to hold firmer prices for desperate buyers while remaining flexible for rational ones.
- **Shared Buyer Fairness Control**: Both MAS and Human Baseline face the **exact same pool of buyers** in each experiment, ensuring scientifically valid results.
- **Multi-API Key Rotation**: Automated rotation between multiple NVIDIA/Groq keys to ensure zero-interruption execution during high-volume benchmarks.

## 🔬 Research Methodology
- **Adversarial Stress-Testing**: Red-teaming loop with market crashes and deceptive bidding.
- **Economic Metrics**: Tracks **PCR** (Profit Capture Ratio), **IV** (Inventory Velocity), and **EE** (Economic Efficiency).
- **Time-Aware Rationality**: Solves the "Rationality Paradox" by implementing heuristic flexibility as expiry approaches.

## 📁 Project Structure
- `src/main.py`: The Multi-Model Benchmark Engine; orchestrates all 5 experiments.
- `src/agents.py`: Upgraded agent logic (Inferential analysis & Time-decay).
- `src/environment.py`: High-fidelity marketplace simulation with Shared Buyer logic.
- `src/visualizer.py`: Generates publication-quality charts and radar maps.

## 🏃 Getting Started
1.  **Environment**: Create a `.env` file with `NVIDIA_API_KEY`, `NVIDIA_API_KEY_2`, etc.
2.  **Run**: `python -m src.main` to execute the full benchmarking suite.
